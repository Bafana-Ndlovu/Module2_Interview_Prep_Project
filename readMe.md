## JavaScript Data Types

# JavaScript data types describe the kind of value a variable can store.

## 📌 Primitive Data Types

# Primitive data types are the basic building blocks of JavaScript.

# String
Used for text.

let name = "Bafana";

# Number

let age = 25;
let price = 99.99;

Used for integers and decimal numbers.

# Boolean

Represents true or false.

let isStudent = true;

# Undefined

A variable that has been declared but has no value.

let result;
console.log(result); // undefined

# Null

Represents an intentional empty value.

let user = null;
